# Molecular Discovery Engine — Portfolio Demo

A public portfolio page introducing an AI-assisted molecular discovery workflow built with Python, LangGraph, Gemini, and RDKit.

**Open the live demo:** https://pazhanipm91.github.io/molecular-discovery-portfolio-demo/

## What this public demo includes

- A responsive, static portfolio page and a small interactive UI preview.
- An overview of the workflow: propose, parse, describe, and iterate.
- Example UI fields that use placeholders rather than molecular data.

## What it does not include

- Private production source code, proprietary prompts, or business logic.
- API keys, credentials, or live API connections.
- Real molecular structures, candidate data, or calculated results.
- Actual molecule generation, chemistry calculations, docking, or binding-affinity prediction.

The page's controls only select among illustrative placeholders. They do not run the underlying private engine. This demo is a software portfolio presentation—not validated chemistry software or an experimental or clinical decision tool.

## Preview locally

Open `index.html` in a browser. The page uses no package manager, external libraries, or API key.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save. GitHub Pages is designed for public repositories on GitHub Free; check the current account and organization settings before enabling it.

## Technology

HTML · CSS · JavaScript · Python · LangGraph · Gemini API · RDKit

The live portfolio page is static HTML/CSS/JavaScript. The Python and AI technologies describe the separate private prototype, not executable functionality on this page.
